# 铁屋叙事 Chat

> “假如一间铁屋子，是绝无窗户而万难破毁的，里面有许多熟睡的人们，不久都要闷死了。然而是从昏睡入死灭，并不感到就死的悲哀。现在你大嚷起来，惊起了较为清醒的几个人，使这不幸的少数者来受无可挽救的临终的苦楚，你倒以为对得起他们么？”
>
> ——当然对得起。非但要嚷，还要做成聊天软件，让每一位愿意醒来的用户，都能在铁屋里免费发言。

## 简介（第一个没烂尾的项目喵）

**铁屋叙事 Chat** 是一款充满人文气息的即时对话应用。它的名字取自鲁迅笔下那间著名的铁屋，致敬那位总也不肯“好好睡觉”的先生。

我们深信，在这个年代，公开发声需要勇气，也需要一个合适的“人设”。为此，本应用提供：

- **高度可定制的 AI 模型**：你可以让 AI 穿上任何一张皮，替你说出你不方便直说的话。
- **系统提示词**：一次设定，终生受用，保证 AI 始终如一地维持某种“形象”。
- **账号一键注销**：当你终于从铁屋里彻底清醒，随时可以不留痕迹地离开。

毕竟，我们卖的是呐喊，不是锁链。
